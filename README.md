# 🗺️ خريطة صنعاء التفاعلية - البلوكات والشوارع

تطبيق خريطة ويب تفاعلي يستعرض المخططات الحضرية، حدود البلوكات، وخطوط الشوارع لمدينة صنعاء فوق صور فضائية عالية الدقة من **Google Satellite**. يُتيح المشروع للباحثين والمشاهدين استعراض البيانات المكانية والاستعلام عن تفاصيل المعالم بسهولة عبر المتصفح.

### 🛠️ التقنيات وأدوات العمل (Tech Stack)

* **Leaflet.js:** مكتبة برمجة الخرائط التفاعلية على الويب (Web GIS).
* **Google Satellite BaseMap:** طبقات الصور الفضائية عالية الدقة كمصدر خلفية مدمج.
* **ArcGIS Desktop (ArcMap):** معالجة البيانات الحيزية وتصديرها إلى GeoJSON.
* **GitHub Pages:** استضافة خفيفة ومجانية للموقع والبيانات الجغرافية.

---

### 📂 ملفات المستودع (Repository Structure)

* `index.html`: كود HTML وJavaScript الرئيسي لتشغيل الخريطة.
* `data.geojson`: ملف البيانات الجغرافية المدمج للبلوكات والشوارع.
* `README.md`: ملف التعريف والتوثيق الخاص بالمشروع.

---

### 📌 المميزات والخصائص

* **عرض صور فضائية:** خلفية عالية الدقة من صور قمر صناعي مع أسماء المعالم.
* **استعلام تفاعلي (Popups):** النقر على أي بلوك أو شارع لعرض البيانات الوصفية.
* **تأطير تلقائي:** ضبط زوم الخريطة ونطاق العرض تلقائياً بناءً على امتداد البيانات.
* **متوافق مع الأجهزة الذكية:** تصميم مرن يشتغل بطلاقة على الموبايل والكمبيوتر.
